Project:
In dit project vind je veel verschillende mappen. De belangrijkste daarvan zijn: Scenes, Scripts, en prefabs

- prefabs: hier vind je alle prefabs en kan je zelf prefabs toevoegen (als je er eentje maakt geef hem dan wel een goeie naam)
- Scripts: hier vind je alle scripts, veel van deze hebben te maken met hoe de vr movement werkt maar ook veel waren van mijn oude project
	   deze zitten geordend in hun eigen map.

- Scenes: 

in de map "Scenes" vind iedereen zijn eigen scene waar hij/zij in kan werken
als je een nieuwe scene wilt maken moet je de "TemplateScene" copy pasten en renamen naar wat je wilt

je kan ook een eigen scene maken.
